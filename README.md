# xtheoputra.github.io

Link hub for **Harasta Rahman Tri Putra** (xTheo, [@xtheoputra](https://github.com/xtheoputra)), founder of [xTheo Labs](https://github.com/xTheo-Labs).

Live: https://xtheoputra.github.io

This root GitHub Pages site also serves the domain-level `robots.txt`, which points crawlers to the sitemaps of the project sites under `xtheoputra.github.io/` (for example [Jago Bahasa](https://xtheoputra.github.io/jago-bahasa/)). Crawlers read `robots.txt` only at the domain root, so a project site can't publish its own.

| File | Purpose |
|---|---|
| `index.html` | Profile page with links and `ProfilePage` / `Person` / `Organization` structured data |
| `robots.txt` | Allows crawling and lists every sitemap on this domain |
| `sitemap.xml` | Sitemap for this page |
| `<key>.txt` | [IndexNow](https://www.indexnow.org/) key for submitting changed URLs to Bing, Yandex, Naver, and Seznam |

Portfolio: https://xtheo-labs.vercel.app
