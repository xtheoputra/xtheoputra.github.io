# Security Policy

## Supported versions

Only the latest commit on the default branch, as published at https://xtheoputra.github.io, is supported.

## Reporting a vulnerability

This is a static GitHub Pages site with no forms, accounts or server-side code. Typical reports are a malicious or hijacked outbound link, injected script or markup, or leaked credentials in the repository.

Do not open a public issue for security problems. Email **mail.harastaputra@gmail.com** with:

- a description of the issue and its impact,
- the page URL or file path,
- steps to reproduce.

You will receive an acknowledgement within 7 days. Please allow time for a fix before disclosing the issue to anyone else.
